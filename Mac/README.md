# 消息回复助手 · macOS

「忙碌消息助手」是一个原生 macOS 应用，在练琴、工作、学习等忙碌时段，使用 DeepSeek 为个人微信的新文字消息生成回复。当前版本为 **0.6.0（构建 7）**。

## 主要功能

- **回复范围**：支持指定好友，或微信聊天列表第一屏中的好友；所有好友模式启动时建立基线，忽略已有未读消息。
- **后台处理**：微信在前台时暂缓界面操作，离开微信后继续；发送前核对好友、消息历史和输入框，保护用户未发送的文字。
- **状态说明**：预设活动和自定义活动分别记住上次编辑的说明，支持自动保存和「保存当前状态」。
- **个人档案**：导入 Markdown 简介，编辑、保存并启用后作为回复背景资料。
- **回复风格**：选择语气、趣味互动程度和话题拓展方式；持续延伸模式会在正常回复中加入相关追问，并在结束或紧急信号出现时收尾。
- **时长与轮数**：忙碌时长可选 5–480 分钟，每位好友可选 1–100 轮或无上限，并提供常用选项。
- **会话记录**：在应用内查看本机处理记录和待发送草稿；发送结果不确定时暂停该好友，避免重复发送。

第一屏模式不会从上到下遍历整个聊天列表。列表位于较低位置时先回到顶部；目标好友不在第一屏时等待其重新出现。当前用于个人私聊，不处理群聊、公众号或系统会话。

## 运行条件

- macOS 14.0 或更新版本；构建时使用当前 Mac 的原生架构。
- 微信桌面版已登录，Mac 保持开机、唤醒和解锁；系统休眠期间无法继续处理。
- 用户自己的 DeepSeek API 密钥，在应用的连接页面填写和管理。
- 在「系统设置 → 隐私与安全性 → 辅助功能」中允许本应用访问微信界面。

首次使用或更新后若辅助功能访问失败，重新添加 `~/Applications/练琴消息助手.app` 并重启应用。应用显示名为「忙碌消息助手」，安装文件名保留「练琴消息助手.app」。

## 构建与使用

安装 Xcode Command Line Tools，确保本机有 Swift 编译器。项目使用 Cocoa、SwiftUI、ApplicationServices 和 Security 系统框架，无第三方包依赖。

从仓库根目录进入 `Mac/`，运行编译与本地测试：

```sh
cd Mac
./05_构建工具/build.command --build-only
```

成功后，应用、ZIP 和生成资源保存在 `06_发布版本/构建产物/`，`06_发布版本/最新构建` 指向最近一次成功结果。此步骤不覆盖已安装应用。

退出正在运行的助手后，安装或更新：

```sh
./05_构建工具/build.command --install
```

脚本先编译、运行测试及核验签名，再备份已安装的旧版并更新 `~/Applications/练琴消息助手.app`。安装后手动打开应用，配置 API、活动说明和回复范围，再开启忙碌模式。

也可以双击 `Mac/` 目录中的快捷入口：

| 文件 | 用途 |
| --- | --- |
| [检查构建.command](检查构建.command) | 编译并运行本地测试 |
| [更新应用.command](更新应用.command) | 备份并安装当前版本 |
| [打开消息助手.command](打开消息助手.command) | 打开已安装的应用 |

## 本机数据与 API

API 密钥保存在 macOS 钥匙串。偏好设置由 macOS 管理；个人档案和会话记录分别保存于：

```text
~/Library/Application Support/WeChatPracticeAssistant/Profile/profile.json
~/Library/Application Support/WeChatPracticeAssistant/Sessions/
```

生成回复时，相关消息和有限的好友上下文会发送给 DeepSeek；个人档案只有在保存并启用后才会随请求附带。Markdown 导入不会修改原文件，也不会加载其中的图片、链接或引用文件。

本机记录、个人简介、偏好快照、密钥和生成的安装备份不应提交到源码仓库。
